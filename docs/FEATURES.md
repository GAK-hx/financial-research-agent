# 功能说明

Morshan接收公司、报告期、分析截止日和研究问题，输出带数据快照、证据引用、风险状态与限制说明的
`RiskAssessmentArtifact`。系统面向研究辅助，不执行交易或下单。

## 财务风险分析

系统集中分析四类相互关联的风险：

- 偿债能力与流动性；
- 盈利质量与经营现金流；
- 资产质量与减值；
- 财务披露与审计异常。

确定性规则先从财务事实中生成风险候选，Agent再结合公告、研报、行情、因子和网络资料进行取证、反证和解释。
证据不足时返回`INSUFFICIENT_DATA`，不会把缺失值填成零或强行给出结论。

## 数据与证据

- 采集日线、财务报表和公告，并保留来源、采集时间与版本；
- 使用Point-in-Time边界阻止分析截止日之后的数据进入结果；
- 通过Iceberg Snapshot管理标准化事实、特征和风险候选；
- 通过Milvus、关键词检索和可选Elasticsearch检索研报及网络资料；
- Evidence记录主体、日期、来源、页码或数据快照，支持结论回查。

## Agent执行

- LangChain统一模型、结构化输出、Tool和Retriever接口；
- LangGraph执行状态化工作流、条件路由、并行任务和Checkpoint恢复；
- Supervisor按题型选择单Agent、固定团队或动态团队；
- Harness控制Tool白名单、参数、预算、并发、超时和修订次数；
- Evaluator检查数值、单位、时间口径、引用和相互冲突的证据。

## 多用户任务

- FastAPI提供异步任务、状态查询、取消、恢复、Trace和SSE；
- PostgreSQL保存任务、租约、事件、Checkpoint和最终结果；
- Redis承担限流、热索引和single-flight并发合并；
- 相同数据版本的公共分析可以跨用户复用，用户报告和会话记忆保持隔离；
- Worker退出后，未完成任务可由其他Worker接管。

## 输出

最终结果包含风险状态、支持证据、反向证据、计算口径、缺失数据、替代解释和引用位置。模型生成的文字不会
直接写成可信长期事实，重要数值与结论必须能够追溯到当前运行的Evidence。
