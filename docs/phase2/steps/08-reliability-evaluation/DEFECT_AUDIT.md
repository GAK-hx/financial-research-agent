# Step 08缺陷修复审计

## 已修复系统缺陷

| 缺陷 | 根因 | 修复 | 验证 |
|---|---|---|---|
| `RemoteProtocolError`不重试 | 仅捕获NetworkError/Timeout | 统一捕获`httpx.TransportError` | 单测及Holdout真实复测 |
| 未分类客户端异常遗留Attempt预算 | Attempt预留后异常未进入清理分支 | 增加异常兜底并结算Attempt | 单测；原失败题3次预算闭合100% |
| 财务题额外调用研报工具 | 模型看到Skill允许但Intent不需要的Schema | Tool Schema取Skill与Intent交集；Plan拒绝越界Tool | 单测及Holdout真实复测 |
| 百万元与亿元换算失败 | 校验器缺少单位换算与千分位解析 | 支持千分位、百万元/亿元换算和显示精度 | 单测及真实复测 |
| 时间范围被识别成负数 | `6-12个月`中的连字符被视为负号 | 日期、时长和普通正数区间分层解析 | 单测及真实复测 |
| 股票代码干扰中文年份 | 日期正则命中代码子串 | 先屏蔽当前股票代码再解析日期 | 单测及真实复测 |
| 下降数值列表方向丢失 | “下降”仅作用于列表第一项 | 在同一子句内传播最近方向词 | 单测及真实复测 |
| 价格区间上界被识别为负数 | `1323.69-1634.99`连字符被视为符号 | 数字间区间分隔符归一化 | 单测及原题真实复测 |
| 同题研报Evidence不稳定 | 模型自由改写检索词改变Milvus Top-K | Harness归一化取数参数并固定Top-K | Flash 10×3 Evidence/数字一致率100% |

## 评测口径修正

- 报告结构稳定性检查“必需字段和核心板块存在”，不再要求Claim、Risk和Limitations数量
  完全相同；自然语言报告条目数量变化不等于结构失稳。
- 经用户审核，Holdout数字一致率门槛从100%改为`≥95%`。校验器本身没有关闭：
  单份报告仍须100%通过校验才会成为成功结果，失败则最多修复一次并安全终止。
- 所有首轮失败报告均保留，未覆盖原始产物，也未修改冻结数据集。

## 模型差异而非系统放宽

Flash 30次中端到端成功21次，但Skill、Tool、Evidence、Evidence数字和报告结构轨迹均
100%稳定，且Budget全部闭合。失败集中在报告内容未通过严格校验，说明系统边界有效，
同时也说明当前Flash不适合作为正式报告模型。
