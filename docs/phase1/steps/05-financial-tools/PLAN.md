# Step 05 — 财务数据与工具

## 目标

建立最小但真实可验证的财务域，不把未完成财务能力注册给Agent。

## 依赖

- Step 01、02完成；
- 财务最小范围已审核。

## 推荐最小范围

利润表、资产负债表和现金流量表保留原始字段；第一版Curated指标限制为营收、归母净利润、同比增长、毛利率、资产负债率、经营现金流和ROE（仅在输入字段足够时计算）。

## 任务

1. 评估AkShare财务接口和字段稳定性；
2. 冻结报表/指标最小字段；
3. 保存原始字段到标准字段映射和单位；
4. 区分报告期与公告日；
5. 建立三张报表或审核后的最小表；
6. 缺失与0分离；
7. 计算指标并记录公式版本；
8. 定义FinancialQuery输入输出；
9. 结果转换为Financial Evidence；
10. 与源数据抽样核对；
11. 只有验收后才注册工具。

## 验收标准

- 至少两只股票多个报告期；
- 关键字段与源一致；
- 单位和报告期明确；
- 公式有测试；
- 数据不足时不强算指标；
- 未验收工具不出现在Registry。

## 降级方案

如果接口字段无法在预定时间冻结，第一阶段允许Financial Tool延后，但需从简历和默认计划中移除“已实现财务分析”，并在阶段验收中记录范围变化。
