# Step 10 20题评测报告

## 1. 数据集

- 版本：`phase1_eval_v1`；
- 截止日期：2026-07-15；
- 行情3题、指标3题、财务3题、研报4题、综合5题、非法输入2题；
- 两只股票均有覆盖；
- 每题声明预期Intent、股票、日期、工具集合和错误语义。

原计划建议未包含Financial域。本次根据已实现功能补入3题，确保行情、财务、研报和综合四类真实模型路径都进入正式评测。

## 2. 评分方式

评分器不调用模型自评，而是确定性核对：

1. `QuerySpec.intent`；
2. Plan工具集合；
3. 股票、起止日期及每个Tool参数；
4. Claim引用是否存在、是否属于当前Run；
5. 使用`ReportValidator`独立重验数字；
6. HTTP、模型Planner、工具、报告和Validation是否共同完成；
7. 非法输入是否按预期受控拒绝。

## 4. 首轮缺陷与修复

首轮基线为任务成功13/20、参数16/18、数字12/18。审计后修复了以下通用确定性缺陷：

- 中文“六个月”未映射为6个月；
- Evidence ID内6位数字被误认为股票代码；
- `7月14日`、`6月30日`和`2026-2028年`被误认为事实数字；
- “微降”未规范化为负方向；
- Evidence研报文本的“下降12.10%”与Claim的负值口径不一致。

每项修复均增加回归测试。真正无Evidence支持的数字、未知引用和错误股票仍会被拒绝。

## 5. 解释边界

最终100%只代表该固定20题集合在当前数据快照、模型和Prompt版本下通过，不代表开放世界准确率。由于首轮结果用于发现并修复确定性缺陷，这组题已经兼具开发回归集属性，不能再视为完全未见的Holdout。

第二阶段应新增：

- 与本集合隔离的未见Holdout；
- 多次重复运行和置信区间；
- 供应商Token/费用统计；
- 更大股票池、跨股票比较和边界日期；
- Provider故障、限流和长任务恢复评测。
