## 已知限制

- 第一版只做向量检索，没有Reranker和关键词Hybrid Search；
- PDF页眉、免责声明仍可能进入Chunk，后续可增加版面规则；
- 当前报告量小，AUTOINDEX足够；扩大语料后再基于评测调整索引参数；
- 首次运行需要下载嵌入模型，之后由Docker卷复用模型缓存。
- RAG镜像显式使用PyTorch CPU wheel，避免在无GPU服务中引入CUDA运行时；最终镜像为2.22GB，未采用CPU限定源时会引入大量无用CUDA组件。
