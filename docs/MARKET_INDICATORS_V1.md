# Market Indicators V1

适用输入：按交易日升序排列的前复权日线。指标由确定性代码计算，不由模型推断。

| 指标 | 定义 |
|---|---|
| 区间收益 | `末日收盘价 / 首日收盘价 - 1` |
| 年化波动率 | 日收益率样本标准差（`ddof=1`）乘以`sqrt(252)`；少于3个价格时为空 |
| MA5/MA20 | 截止实际末交易日最近5/20个收盘价算术平均；数据不足时为空 |
| 最大回撤 | `min(close / cumulative_max(close) - 1)` |
| 相对20日均量 | 最新成交量 / 最近20个交易日成交量平均值；不足20日或均量为0时为空 |
| 区间高低 | 区间内`high`最大值和`low`最小值 |

版本：`market_indicators_v1`。

所有结果必须同时披露请求日期、实际首末交易日、数据截止日、Iceberg Snapshot和输入Locator。
