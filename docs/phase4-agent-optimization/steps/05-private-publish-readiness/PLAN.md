# Step 05：私有发布前验证

## 目标

在创建私有 GitHub 仓库前，验证扩展股票池、重叠查询、多用户并发、身份隔离、报告校验和
Secret 边界。此步骤不改变仓库可见性，也不授权公开发布。

## 工作项

1. 将本地验收股票池扩展到20支，检查重复键、OHLC合法性、日期覆盖和抽样一致性；
2. 为AkShare东方财富日线接口增加有界重试，并以腾讯日线接口作为同口径回退；
3. 用5个用户并发查询，每人查询4～5支股票，允许不同用户重复查询热点股票；
4. 修正多股票技术比较的意图路由、计划边界和执行参数归一化；
5. 将Evidence分为可内联的小型聚合结果与需要压缩的大批量明细；
6. 将报告校验改为硬边界与软格式检查分离；
7. 完成完整Docker/PostgreSQL回归、Ruff和候选文件Secret扫描；
8. 仅在全部Gate通过后创建私有GitHub仓库。

## 不在本步骤实现

- 不公开GitHub仓库；
- 不实现分钟级、实时行情或自动交易；
- 不把研报全文读取放进每次普通查询；
- 不在没有真实消费者时增加MCP服务器。
