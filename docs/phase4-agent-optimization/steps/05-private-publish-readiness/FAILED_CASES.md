# Step 05 失败与修正记录

## AkShare东方财富接口不稳定

- 表现：批量采集时出现SSL断开或远端主动关闭连接；
- 原因：公开接口可能受频率、IP或上游稳定性影响；
- 修正：增加有界重试与指数退避，并使用腾讯日线接口回退；
- 复验：20支股票全部完成入湖，质量Gate通过。

## 多股票比较误路由为单股技术分析

- 表现：模型创建多个单股任务并超过Skill工具预算，或只分析第一支股票；
- 原因：意图解释器先匹配“技术面”，后匹配“比较”；多股票参数归一化还会错误覆盖为第一支股票；
- 修正：多股票比较优先路由为`screening`，只允许一个覆盖全部股票的比较任务；
- 复验：5个并发请求均只调用一次`stock_comparison`。

## 聚合Evidence被过度压缩

- 表现：工具返回完整指标，但报告声称没有具体数值；
- 原因：上下文构建器按`rows`字段名删除全部行，包括4～5行的小型聚合结果；
- 修正：20行以内聚合结果直接进入模型上下文，大批量明细继续压缩并保留来源定位；
- 复验：报告能够使用波动率、回撤、动量和Amihud指标。

## 报告校验误报

- 表现：`20日`、`60日`窗口被当作事实数值，小数尾部六位被当作股票代码；
- 修正：窗口参数不进入数值事实校验，小数内部不参与股票代码识别；未请求域由Harness归一化为未知；
- 复验：最终多用户Gate 5/5通过。

## 完整回归身份模式不一致

- 表现：首轮完整测试6项API断言收到401；
- 原因：并发Gate使用`api_key`模式，离线CI测试预期`local`模式；
- 修正：完整回归显式设置`IDENTITY_MODE=local`；
- 复验：177/177通过。

## GitHub Actions缺少持久化测试依赖

- 表现：`offline-ci`在`Unit tests without external services or model API`步骤失败；
- 远程输出：177项测试中1项错误、23项跳过，错误用例为
  `test_encrypted_serializer_round_trip_and_wrong_key_failure`；
- 原因：工作流仅安装`.[dev]`，加密检查点序列化测试实际依赖`persistence` extra中的
  `pycryptodome`；
- 修正：离线CI安装范围改为`.[dev,persistence]`；
- 边界：仍不启动PostgreSQL、模型API、行情网络、Spark或RAG重型依赖；
- 目标：保留完整177项离线单元测试入口，并由环境开关继续跳过需要真实外部服务的用例。
