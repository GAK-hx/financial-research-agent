# 研报两级检索与按需深度分析

## 设计目标

普通股票查询不应默认读取、切分和校验大量研报全文。研报能力拆成低成本初筛与按需深析，
同时保留来源追踪。

## 一级：元数据与摘要初筛

输入包括股票、时间范围、机构、报告类型和关键词。只访问结构化元数据、标题、摘要与向量索引，
返回候选清单，不生成完整研报结论。

- 用户指定时间时严格使用该范围；
- 未指定时默认最近90天、Top 5；
- 结果不足时可扩展到180天，并在响应中标记范围扩展；
- 基础检查只验证股票、日期、来源定位和租户权限。

## 二级：按需深度分析

以下情况才读取候选研报的全文或相关页：

- 用户明确要求机构观点、分歧、目标价、催化剂或风险；
- 用户从候选清单选择指定研报；
- 工作流需要把研报观点与行情、财务或事件Evidence联合分析。

深析阶段执行分块检索、页码与机构归属、关键结构化事实核验、跨报告观点对比和引用生成。
模型仍不能直接访问数据库或任意文件，只能通过受控研报工具取得内容。

## 校验分档

| 档位 | 硬校验 | 软检查 |
|---|---|---|
| 初筛 | 身份、股票、日期、来源、结果数量 | 相关度、摘要完整性 |
| 深析 | 引用ID、机构/页码归属、结构化关键事实 | 风险向量、情景、表达格式 |

自然语言中的所有数字不再统一用正则判定。目标价、盈利预测、财务指标等先提取成带单位、期间、
来源ID的`Fact/Metric`，再进行类型化核验。
