# Financial Metrics V1

## 数据范围

来源为AkShare `stock_financial_report_sina`。Raw层保留三张报表的全部返回字段；Curated层只保存已冻结字段：

- 利润表：营业收入、营业成本、归母净利润；
- 资产负债表：资产总计、负债合计、归母权益；
- 现金流量表：经营活动现金流量净额；
- 公共字段：报告日、来源返回的公告日期、币种和合并口径。

金额单位保持来源原始单位，当前两只验收股票均为CNY元。缺失值保持为空，不用0替代。

## 指标公式

| 指标 | 公式 |
|---|---|
| 营收同比 | `本期累计营业收入 / 上年同期累计营业收入 - 1` |
| 归母净利润同比 | `本期累计归母净利润 / 上年同期累计归母净利润 - 1` |
| 毛利率 | `(营业收入 - 营业成本) / 营业收入` |
| 资产负债率 | `负债合计 / 资产总计` |
| 期间ROE | `本期累计归母净利润 / ((上年末归母权益 + 本期末归母权益) / 2)` |

同比基期、分母或权益数据不足时返回空值。季度ROE不年化。公式版本为`financial_metrics_v1`。

## 公告日期限制

Sina接口的历史`公告日期`可能反映后续更新或重述，而不是首次披露日。例如当前Raw响应中，600519的2024-03-31报告期返回`公告日期=2025-04-30`，但`更新日期`为2024-04-26。

因此Curated字段应理解为`source_announcement_date`：

- 可用于展示来源返回的日期；
- 不可用于严格的历史时点回测；
- Financial Tool明确返回`point_in_time_eligible=false`；
- 正式时点研究需要后续接入交易所公告或可靠的首次披露日数据源。
