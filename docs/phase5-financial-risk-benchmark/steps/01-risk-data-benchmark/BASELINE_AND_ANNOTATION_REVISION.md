# Step 01-D 基线与标注抽样修订记录

## 修订前问题

- 统计基线按全部可用历史期间的 70/30 自动切分。100家公司初次完整运行产生训练2,500例、测试1,100例，
  测试开始于2014年。该划分技术上无随机未来泄漏，但测试期太长且包括与当前业务差异较大的旧报表；
- 标注候选按代码和报告期升序取前120/120/60例。盲审包出现1994年等早期报告，同一公司和缺少证据的
  案例过于集中，难以代表当前财务风险监测任务。

## 修订后固定规则

- 统计基线只保留2016年及以后年报，训练截至2022年，测试从2023年开始；仍按下一年度严重信号的
  程序化 Proxy 计算，不声称这是历史 Point-in-Time Gold 或真实风险预测效果；
- 规则基线不再读取以当前分析截止日汇总的候选分数；只用与逻辑回归相同的当期财务/审计特征按 Registry
  阈值计算，排除报告期后才发生的更正、问询等回溯披露事件。即便如此，历史修订快照缺失仍使严格历史
  Point-in-Time 指标保持未验证；
- 标注候选仅取2020年及以后年报，并按发行人轮转抽样后冻结120风险候选、120对照和60不足案例；
- 30例盲审包提供公司名称和13项特征的数值、单位、可用性、源记录编号，但隐藏规则状态与候选分组；
- 已填人工标签的 CSV 受到覆盖保护。两名标注者未独立完成前，kappa Gate 保持待人工。

修订原因是业务时点和样本可复核性，而不是根据任何私有 Holdout 效果调阈值。修订前基线仅作为
管线预检：规则 Precision 0.1610 / Recall 0.9658 / PR-AUC 0.2115；逻辑回归 Precision 0.2440 /
Recall 0.5616 / PR-AUC 0.2546，均为程序化 Proxy，不能与修订后的正式时间切分直接比较。
