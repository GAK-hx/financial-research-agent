# 历史Point-in-Time回放与提前量说明

## 结论

03-A已完成。系统在Docker内对5个历史`as_of_date`重建了来源时间可见的财务事实、特征和规则候选，
共生成126,880条特征和39,040条候选；各回放点PIT泄漏、特征主键重复和候选主键重复均为0。
同一配置再次执行后，汇总JSON逐字段一致。

这是一项`source-time backfill replay`：记录的来源发布时间覆盖历史年份，但系统是在2026年完成回填。
因此结果证明“按来源发布时间可重建”，不声称系统在历史年份真实持有这些记录。

## 增量边界

相邻回放点仅约5.1%～9.4%的候选自然键新增或发生状态、触发指标、证据变化，意味着约90%+的
候选可作为后续增量重算与公共Artifact缓存的潜在复用对象。这是扫描边界估计，不是尚未实现的增量性能成绩。

## 风险提前量与概率校准

效果指标继续使用公开V4FinBench的一年期前瞻任务，不在自有数据上构造风险标签：A2的五折
PR-AUC为0.0638、ROC-AUC为0.9329、Brier为0.00313、ECE为0.000594。排序指标相对A1明显改善，
但ECE未改善，因此只声称完成一年期前瞻排序和校准报告，不声称概率质量全面提升。

当前没有继续下载`h=2/h=3`数据；项目所需的明显相对效果已经得到验证，额外期限不作为简历达标条件。
